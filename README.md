# Prayer App

An application inspired by my own struggles as a Christian living away from home and Matthew 18:20

*“For where two or three are gathered together in My name, I am there in the midst of them.” - Matt. 18:20*

I hope the application brings Christians or anyone who is intrigued or questioning God to come together in prayer, encouraging one another and bearing one another's burdens.

## Getting started
This project uses the React Native Expo full-stack framework. 

Prerequisits:
- Node.js
- npm

To get started simply clone the repository into your local development environment.

Ensure that you have expo version 54.0.13
If you dont have Expo installed, simply install it by running:
```bash
npm install -g expo-cli
```

open the project in your desired code editor and in the built in terminal or opening the project in terminal, run 
```bash
npm install
```

## Features
1. Adding, editing, tracking and viewing prayer requests
    - Also includes viewing prayer requests of other users.

2. Option to keep your requests anonymized or let other users know of your requests.

3. Following other users to keep up to date with their prayer requests.
    - Notifying other users that you have prayed for their requests
    - Reacting to prayer requests
    - 
4. Informing other users that you have prayed for the request.
